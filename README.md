# Projeto WEB — New York City

## Sobre o projeto
Site informativo sobre Nova York desenvolvido como projeto acadêmico/prático para exercitar HTML semântico, organização de páginas, CSS, navegação e recursos multimídia.

## Objetivo
Praticar fundamentos de desenvolvimento web e transformar o conteúdo estudado em uma aplicação navegável e apresentável.

## Funcionalidades
- Página inicial com conteúdo sobre Nova York
- Navegação entre páginas
- Seção de pontos turísticos
- Uso de imagens, vídeo, áudio e conteúdo incorporado
- Estrutura com elementos semânticos de HTML
- Estilização com CSS

## Tecnologias
- HTML5
- CSS3
- JavaScript (arquivo `back.js` em exercício inicial)

## Como executar
1. Clone o repositório.
2. Abra o arquivo `index.html` no navegador.
3. Para acessar a seção de pontos turísticos, use o link existente na página inicial.

Não há dependências ou processo de build necessário para a versão atual.

## Aprendizados
- Estrutura semântica de páginas HTML
- Organização de conteúdo e navegação
- Estilização com CSS
- Inserção de recursos multimídia
- Publicação e organização de projeto no GitHub

## Status
Projeto acadêmico em evolução.
